# 프로젝트 요구사항

## 프로젝트 목적

- 반도체 제조 공정 엔지니어의 원인 분석 시간을 단축한다.
- 공정 이상 징후를 사전에 탐지한다.
- 수율 저하 시 원인 후보 Step, R, D, EQ를 제공한다.
- 기존 SOP 알람을 대체하지 않고 의사결정을 지원한다.

## 전체 예정 흐름

CSV 업로드  
→ 데이터 검증  
→ 데이터 전처리  
→ 머신러닝 예측  
→ SHAP 원인 후보 분석  
→ Next.js 대시보드  
→ FastAPI  
→ n8n 자동화  
→ Slack 알림

## 현재 데이터 정의

- `Lot_Wafer_ID`: Wafer 식별자
- `Y`: 최종 수율
- `Y1`~`Y5`: Fail Rate
- `Y6`~`Y10`: Fail Bit Count
- 컬럼명이 `_R`로 끝나면 Response
- 컬럼명이 `_D`로 끝나면 Defect
- 컬럼명이 `_EQ`로 끝나면 Equipment

## 중요 설계 원칙

- 특정 CSV 파일명을 코드에 하드코딩하지 않는다.
- Step 개수와 컬럼 개수를 하드코딩하지 않는다.
- R, D, EQ 컬럼은 이름 규칙으로 자동 탐지한다.
- 향후 멘토가 새 데이터셋을 제공하면 쉽게 교체할 수 있어야 한다.
- 원본 데이터는 수정하거나 덮어쓰지 않는다.
- Y 예측 시 Y1~Y10을 입력 변수로 사용하지 않는다.
- 모델 성능이 낮으면 원인을 확정적으로 표현하지 않는다.
- 실제 설비 자동 제어는 구현 범위에서 제외한다.

## 데이터 교체 및 재학습 계획

현재 데이터는 합성 데이터일 가능성이 있다. 추후 멘토가 제공하는 새
데이터로 교체하고, 새 데이터의 특성에 맞춰 전처리 규칙을 재검토한 뒤
모델을 다시 학습할 예정이다.
